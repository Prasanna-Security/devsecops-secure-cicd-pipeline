# DevSecOps Secure CI/CD Pipeline

## Project Overview

This project demonstrates how to integrate security into the software development lifecycle using Git, GitHub Actions, and open-source security tools.

The objective is to detect security issues early, protect source code, automate security checks, and enforce secure collaboration practices.

## Objectives

- Prevent accidental exposure of secrets.
- Integrate automated security scanning into CI/CD.
- Protect important branches through review policies.
- Implement repository access control and code ownership.
- Identify vulnerable dependencies and manage updates.

## Technology Stack

- Git and GitHub
- Gitleaks
- GitHub Actions
- Git pre-commit hooks
- Dependabot
- YAML
- Python (sample application)

## Planned Security Controls

1. .gitignore configuration
2. Git pre-commit hooks
3. Gitleaks secret detection
4. Repository and Git history scanning
5. GitHub Actions security workflow
6. Branch protection rules
7. Role-Based Access Control (RBAC)
8. Mandatory pull request reviews
9. CODEOWNERS
10. Dependabot dependency updates

## Project Status

Initial repository setup completed.

Security controls will be implemented and tested incrementally. This README will be updated with configuration details and test evidence as the project progresses.

## Learning Outcomes

- Understand Git repository security.
- Implement automated security checks.
- Learn CI/CD security fundamentals.
- Practise secure code review and dependency management.
